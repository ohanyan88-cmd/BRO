# Durable Learning Memory Acceptance / Durable Learning Memory-ի ընդունման չափանիշներ

## English

Repository acceptance requires durable conversation persistence, evidenced ACT outcome recording, repeated-success lesson accumulation, guarded candidate lifecycle, and tests proving that learning failure cannot alter an already verified action receipt.

Production acceptance is separate: deploy the merged revision, confirm the production CLI writes to and restores from the durable database, complete a real governed ACT with external readback, verify a lesson is stored, then demonstrate that a later related interaction receives the lesson as context.

## Հայերեն

Repository acceptance-ի համար պետք է աշխատեն durable conversation persistence-ը, evidenced ACT outcome recording-ը, repeated-success lesson accumulation-ը, guarded candidate lifecycle-ը, և tests-ը պետք է ապացուցեն, որ learning failure-ը չի կարող փոխել արդեն verified action receipt-ի ճշմարտությունը։

Production acceptance-ը առանձին է․ merged revision-ը պետք է deploy անել, հաստատել, որ production CLI-ն գրում և վերականգնում է durable database-ից, իրական governed ACT-ը հասցնել external readback-ի, ստուգել, որ lesson-ը պահվել է, հետո ցույց տալ, որ հաջորդ related interaction-ը այդ lesson-ը ստանում է որպես context։
